# WAND Overview

WAND는 Tencent Cloud의 미디어 AI 플랫폼으로, 미디어 처리 서비스(MPS)의 전통적인 미디어 파이프라인 기능과 최신 AIGC 생성 엔진을 하나의 API 체계로 제공합니다.

## 호출 방식 한눈에 보기

| 구분 | 호출 방식 | 인증 | 대표 API |
|------|-----------|------|----------|
| AIGC 생성 (Image/Video/3D/Music) | 비동기 (TaskId 발급 후 결과 조회) | TC3-HMAC-SHA256 서명 | `CreateAigcImageTask`, `CreateAigcVideoTask` |
| AIGC Text | 동기 (OpenAI/Anthropic 호환 게이트웨이) | API Token (Bearer) | `/v1/chat/completions` 등 |
| MPS 미디어 처리 | 비동기 (TaskId 발급 후 결과 조회) | TC3-HMAC-SHA256 서명 | `ProcessMedia`, `ProcessImage` |
| TokenHub | 동기 (OpenAI 호환) | API Key (Bearer) | `/v1/chat/completions` |
