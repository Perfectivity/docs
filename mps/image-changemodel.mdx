원본 모델 이미지와 의류 이미지를 입력받아 같은 의류를 다른 체형의 모델이 착용한 것처럼 변환합니다. 이커머스 모델 교체, 체형별 착용 컷 생성, 광고 소재 커스터마이징에 사용합니다.

## 요청 방법

| 항목 | 값 |
|------|------|
| API Action | `ProcessImage` |
| 엔드포인트 | `mps.tencentcloudapi.com` |
| API 버전 | `2019-06-12` |
| 인증 | TC3-HMAC-SHA256 (SecretId/SecretKey 서명) |
| 요청 방식 | HTTP POST, JSON |
| ScheduleId | `30110` |

비동기 태스크입니다. 호출이 접수되면 `TaskId`가 즉시 발급되고, 처리 결과는 `DescribeImageTaskDetail`로 조회합니다. `Status`가 `FINISH`이고 `ErrMsg`가 비어 있어야 성공입니다.

## 요청 파라미터

| 파라미터 | 타입 | 필수 여부 | 예시 | 설명 |
|---------|------|-----------|------|------|
| InputInfo | Object | 필수 | `{"Type":"URL","UrlInputInfo":{"Url":"https://example.com/model.jpg"}}` | 원본 모델 이미지. `Type`은 `URL` 또는 `COS`, COS는 `CosInputInfo`에 Bucket/Region/Object 지정 |
| OutputStorage | Object | 필수 | `{"Type":"COS","CosOutputStorage":{"Bucket":"mybucket-125xxx","Region":"ap-guangzhou"}}` | 출력 저장소. COS Bucket과 Region 지정 |
| OutputDir | String | 선택 | `/output/changemodel/` | 출력 디렉터리. 기본값 `/output/changemodel/` |
| OutputPath | String | 선택 | `/output/changemodel/result.jpeg` | 커스텀 출력 경로. 파일 확장자를 포함해야 함 |
| ScheduleId | Integer | 필수 | `30110` | 모델/체형 교체 시나리오 ID |
| AddOnParameter.ImageSet.N.Type | String | 필수 | `garment` | 보조 이미지 유형. 의류 이미지는 `garment` 고정 |
| AddOnParameter.ImageSet.N.Image | Object | 필수 | `{"Type":"URL","UrlInputInfo":{"Url":"https://example.com/dress.jpg"}}` | 의류 이미지. InputInfo와 동일한 구조 |
| StdExtInfo | String(JSON) | 필수 | `{"ChangeGarmentModelConfig":{"BodyShape":"hourglass","PrecisionScale":1.0}}` | 체형 변환 설정. JSON 문자열로 직렬화해서 전달 |
| StdExtInfo.ChangeGarmentModelConfig.BodyShape | String | 선택 | `pear` | 목표 체형. `hourglass`(기본값) / `rectangle` / `plus-size` / `apple` / `pear` |
| StdExtInfo.ChangeGarmentModelConfig.PrecisionScale | Float | 선택 | `1.5` | 정밀도 배수. 0.01~2.0, 기본값 `1.0`. 높을수록 정확하지만 처리 시간 증가 |

## 응답 파라미터

| 파라미터 | 타입 | 필수 여부 | 예시 | 설명 |
|---------|------|-----------|------|------|
| TaskId | String | 항상 | `2600007696-WorkflowTask-hIJK8901LM2345` | 발급된 태스크 ID. `DescribeImageTaskDetail` 조회에 사용 |
| RequestId | String | 항상 | `3c140219-cfe9-470e-b241-907877d6fb03` | 요청 식별자 |

`DescribeImageTaskDetail` 조회 결과의 주요 필드는 다음과 같습니다.

| 파라미터 | 타입 | 필수 여부 | 예시 | 설명 |
|---------|------|-----------|------|------|
| Status | String | 항상 | `FINISH` | 태스크 상태. `FINISH`면 처리 완료 |
| ErrMsg | String | 항상 | - | 실패 원인 메시지. 성공 시 빈 값 |
| CreateTime | String | 항상 | `2025-05-21T10:00:00Z` | 태스크 생성 시각 |
| FinishTime | String | 완료 시 | `2025-05-21T10:00:18Z` | 태스크 완료 시각 |
| Outputs.N.Path | String | 성공 시 | `/output/changemodel/result.jpeg` | 결과 이미지의 COS 경로 |

## 호출 예시

```python
import json
from tencentcloud.common import credential
from tencentcloud.common.profile.client_profile import ClientProfile
from tencentcloud.common.profile.http_profile import HttpProfile
from tencentcloud.mps.v20190612 import mps_client, models

cred = credential.Credential("<SecretId>", "<SecretKey>")
http_profile = HttpProfile()
http_profile.endpoint = "mps.tencentcloudapi.com"
client = mps_client.MpsClient(cred, "ap-guangzhou", ClientProfile(httpProfile=http_profile))

# 모델/체형 교체 태스크 제출 (원본 URL + 의류 URL)
params = {
    "InputInfo": {
        "Type": "URL",
        "UrlInputInfo": {"Url": "https://example.com/model.jpg"}
    },
    "OutputStorage": {
        "Type": "COS",
        "CosOutputStorage": {"Bucket": "mybucket-125xxx", "Region": "ap-guangzhou"}
    },
    "OutputDir": "/output/changemodel/",
    "ScheduleId": 30110,
    "AddOnParameter": {
        "ImageSet": [
            {
                "Type": "garment",
                "Image": {
                    "Type": "URL",
                    "UrlInputInfo": {"Url": "https://example.com/dress.jpg"}
                }
            }
        ]
    },
    "StdExtInfo": json.dumps({
        "ChangeGarmentModelConfig": {
            "BodyShape": "pear",
            "PrecisionScale": 1.5
        }
    })
}

req = models.ProcessImageRequest()
req.from_json_string(json.dumps(params))
resp = client.ProcessImage(req)
print(resp.to_json_string())
```

```python
# 태스크 결과 조회
query = models.DescribeImageTaskDetailRequest()
query.from_json_string(json.dumps({"TaskId": "<TaskId>"}))
detail = client.DescribeImageTaskDetail(query)
print(detail.to_json_string())
```

## 주의사항

<Warning>
의류 이미지는 필수입니다. `AddOnParameter.ImageSet`에 `Type=garment` 항목이 없으면 태스크를 제출할 수 없습니다.
</Warning>

<Warning>
`Status`가 `FINISH`여도 성공을 의미하지 않습니다. `ErrMsg`가 비어 있는지 반드시 함께 확인합니다.
</Warning>

<Note>
`PrecisionScale`을 키우면 디테일 정확도가 올라가지만 처리 시간이 늘어납니다. 기본값 `1.0`이 대부분의 장면에 적합하고, 디테일이 중요한 경우 `1.5`~`2.0`까지 올릴 수 있으나 처리 시간이 두 배 가까이 증가할 수 있습니다.
</Note>

<Note>
URL 입력은 공개 접근이 가능해야 하고, COS 입력은 MPS 서비스에 해당 Bucket의 읽기 권한이 있어야 합니다. 원본 이미지와 의류 이미지는 서로 다른 Bucket에 두어도 됩니다.
</Note>
